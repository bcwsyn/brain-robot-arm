# 第五步补充：腕部相机倾角修正与验证

日期：2026-10-14。范围：`simulation/`，GitHub 工作区 `simulation_cup_wrist/`。承接[单腕部 Gemini 2 安装报告](第五步补充_单腕部Gemini2相机安装与视觉接入.md)。本次修正安装倾角，保留原有安装位置、YOLO 权重、力反馈及杯子模型。

## 1. 角度来源与参考方向

用户给出的手工比值为 `2.45/6.8`，因此 `atan2(2.45, 6.8)=19.813793°`。对[用户标注照片](wrist_camera/tilt_reference.png)的红色斜线作二维直线提取，相对图像竖线约18.3–18.6°；方向向夹爪中心收拢，与手工比值一致。照片有透视和手绘误差，不把二维红线拟合当成精确三维标定。本次采用手工比值，照片用于核对方向和参考轴。

图中较小角是光轴相对夹爪向前轴的偏转，设为约 **19.81°**；与其垂直的法兰参考平面的夹角为约 **70.19°**。这里的参考平面随机械臂末端运动，不是固定世界坐标的桌面。相机相对世界水平面的角度会随关节改变。

![模型法兰坐标的X-Z侧视示意](wrist_camera/camera_tilt_geometry.png)

## 2. 模型修改

唯一的安装模型仍为 `src/piper_description/urdf/gemini2_wrist_camera.xacro`，Gazebo 和 MoveIt 共用。新增可调参数 `tilt_rad`，默认 `atan2(2.45,6.8)`；安装关节旋转由 `rpy=(0,-π/2,0)` 改为 `rpy=(0,-π/2+tilt_rad,0)`。外壳、碰撞体、惯性坐标及传感器整体随安装关节旋转。

相机光学 `+Z` 在夹爪坐标中变为 `[sin(tilt),0,cos(tilt)]`，即从侧面 `x=-55 mm` 朝中心 `+X` 倾斜。前端名义光学参考点位置 `(-55,0,30.8) mm` 保留，距指尖参考位置的轴向间距仍为105 mm。横向偏移、名义光心及手工角度均不是实机手眼标定结果。

原观察姿态关节5为0.44 rad；新增相机倾角后会使杯子靠近视野上边缘，所以将固定桌面观察姿态调整为 `[-0.27,0,0,0,0.15,0] rad`。该姿态不读取Gazebo目标位姿，通过MoveIt规划及碰撞检查进入。

视觉仍只使用腕部RGB/深度/内参和图像时刻的机器人TF。没有增加固定外部相机，没有重训或更换YOLO，仍在远处锁定有效估径包后执行近距离力反馈抓取。

## 3. 验证结果

模型核验确认Gazebo/MoveIt两套展开URDF完全一致，光轴方向、19.81°偏转及70.19°互余关系正确，105 mm轴向间距、外壳尺寸和150 mm最小深度保留。96项核心检查通过，0失败/错误/跳过。

固定代码75 mm杯两轮批次，种子20261015，依次A/B放置；会话 `cup-20261014-231434-893953`，两轮均完成实际夹持、抬升、保持、搬运、释放落稳和回零。

独立发布目录图形取放通过1/1，完成后R重新进入观察位并识别，Q正常清理退出；其结果单独记录，不重复计入上述两轮。发布目录模型核验和96项核心检查均通过。图形画面显示倾角增加了近处夹爪遮挡，分割掩膜存在部分夹爪混入；深度/几何过滤后仍可估计未被遮挡的抓取区域，不能据此声称完整轮廓或复杂遮挡能力已解决。

未重新执行全部55/85 mm及故障批次，不将之前未倾斜或固定相机版本的结果计入本次。手工角度只建立近似安装模型，没有连接真实硬件，也没有证明真实复杂环境识别能力。

## 4. 可视化复现

详细环境、构建和按键：[中文指南](wrist_camera/README.zh-CN.md) / [English guide](wrist_camera/README.en.md)。本机：

```bash
cd /home/young1x/robot_projects/piper_robot/simulation
bash scripts/build_simulation.sh
source /opt/ros/humble/setup.bash
source install/setup.bash
export PYTHONNOUSERSITE=1
/usr/bin/python3 -s scripts/verify_wrist_camera_model.py
bash scripts/run_cup_grasp_sim.sh --seed 20261015
```

GitHub用户先pull，再进入 `brain-robot-arm/simulation_cup_wrist` 运行同样步骤；首次使用还需按指南配置私有视觉环境。等待观察位和 `[就绪]`，在启动终端按S抓取、R复位、Q退出。相机倾斜外壳可在Gazebo/RViz观察，检测画面来自同一台腕部相机。
