区域是在看过第一张原RGB后、运行数值前固定的三个矩形，所有28帧均用相同区域，并与原环带相交；不是自动材质分割、现场实测平面身份或新的通用ROI。查看[固定区域叠图](fixed_regions_witness.png)核对实际选择；[逐帧报告](report.json)保留每个候选、失败和数值，不挑帧。

原环带把不同支撑面混在一起，低于原60%主导面要求；局部桌垫拟合通过且高度约31mm，符合29±6mm的既有几何范围。这是定位分析取样影响的证据，不证明黑/白面的实际高度或唯一物理成因，也不把颜色差自动解释成几何差。

**修环带并不能单独挽救本批。** 两个桌垫局部给出的顶面内点仍为692—736（中位717.5），没有达到800。与原主面候选中心的最大差分别只有0.137mm/1.025mm，但它们用同一批深度点、不是独立真值，不能据此认证1cm绝对精度。

另外只在离线复制参数中将颜色掩膜收缩从1像素改成0作敏感性对照：主面内点754—796（中位775.5），仍0帧到800；中心变化0.330—1.583mm（中位0.906mm）。没有写回配置，不把这个对照当新好帧。总选中879—942个原生点不等于同一平面内点数；不能将两者混用。

法向差也受区域影响：左侧桌垫对主面约6.01°，下方桌垫约10.10°，白桌约10.95°（各中位数）。因此不能用本批继续声称“只有某个固定法向差且已知原因”；局部平面/观察范围/材质偏差仍需多组数据区分。刚性安装TF不用于本分析，未尝试用它抹平夹角。
