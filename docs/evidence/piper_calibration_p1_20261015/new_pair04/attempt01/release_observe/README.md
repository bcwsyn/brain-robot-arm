**这是原接管代码的缺陷，不是深度门、MoveIt规划或硬件故障的猜测。代理应在arm前识别越界起点，本次没有提前识别，不应把这次非请求运动归咎操作者。** 不能将原函数的“限位裁剪”当作已批准的恢复轨迹。没有扩大软件/模型/固件限位，没有现场重复复现。
