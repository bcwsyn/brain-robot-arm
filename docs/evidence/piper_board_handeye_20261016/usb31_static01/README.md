## 判断与下一步

恢复xHCI后原RGB链立刻出图，而EHCI下多个有限原生/ROS对照为零帧，支持原虚拟USB2路径与本机RGB阻断相关；**不等于厂商规定相机硬需USB3.1**。保留当前已工作的设置，不再全局切2.0或要求用户Windows相机对照。CAN现在也在xHCI，静止被动窗通过**不证明旧主动发送停流问题永久解决**。
