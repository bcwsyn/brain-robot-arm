## 两个需要纠正的前提

1. “机械臂必须USB2.0”尚未证实。2.0只是已批准的一次虚拟控制器隔离试验；USB3.x控制器能承载USB2速率设备，不能因CAN是低速设备就认定它只能用2.0。旧xHCI路径实际停流仍需解释，但不等于整个USB3.x协议不支持该设备。
2. “相机必须USB3.1”目前只有用户提出的问题，缺具体弹窗/规格或透传测试。上一真实枚举RGB2bc5:0557和深度2bc5:0657都为480M/high-speed（原board_resume02/03和私有宿主日志已存），故不能仅凭旧VM兼容性标签认定相机硬性需要5/10Gbps。480M也**不保证**这套VMware2.0路径上的实际双流能正常运行，仍需后续真实透传和采流验证。
