# ArmRobotUA 现场 CPV 复位步骤（2026-10-12）

本步骤针对当前夹爪反馈 `0x3A7 status=0`、普通 SDK 使能/目标无效的状态。厂家公开回复要求使用最新版 ArmRobotUA，进入 CPV 模式（密码 `agx123`），完成 CPV 复位后重新设置零点；没有授权 Linux 侧继续猜测原始 CAN 帧。

## 现场操作

1. 机械臂保持静止，夹爪附近无物体；确认急停可用、机械臂有支撑。先停止 Linux 侧的 PiPER、ROS、视觉和一键脚本，关闭任何占用同一 USB-CAN 的程序。
2. 在 Windows 主机或可直通 USB-CAN 的 Windows 环境中，使用厂家提供的**最新版** ArmRobotUA。仓库内 `reference/piper_firmware_2026-09/ArmRobotUA_V1.6.3.260828_release.exe` 只作已有资料备份，不能假定它就是 issue 附件中的最新 ZIP。
3. 连接 USB-CAN、给机械臂上电，在 ArmRobotUA 中选择对应 CAN 端口并连接。确认能看到六轴和夹爪反馈后，再进入零点/校准相关页面。
4. 选择软件中的 CPV 模式/CPV 复位入口，输入密码 `agx123`。只执行 CPV 复位，**不要点击固件升级、刷写或其他电机零点操作**；按照软件对 CPV 过程的提示完成一次，不重复点击。
5. CPV 完成后退出 CPV 页面，按上位机提示重新设置零点。对夹爪：让两指机械上完全闭合，在确认没有夹持物后使用上位机的夹爪“当前位置设零/Set zero”操作一次。厂家回复还提示 CPV 后可能需要重新设置机械臂各关节零点；若上位机提示全臂零点失效，先按厂家手册完成全臂零点，不要直接运行一键抓取。
6. 在上位机内做最小开合确认：夹爪使能，打开到较大开口，确认两指实际移动且位置读数变化；再闭合，确认读数回到闭合基准。记录开、闭读数和是否报错。不要以“命令已发送”代替实体位移。
7. 关闭 ArmRobotUA 并断开 Windows 对 USB-CAN 的占用，再恢复 Linux 的 `can0`。先做被动 CAN 读取；只有看到原始 `0x3A7` 状态为 `0x40` 且位置有变化，才在 Linux 侧做一次 50 mm 夹爪目标验证，最后才运行唯一一键脚本。

## 当前验收门

- CPV 后：`0x3A7 status=0x40`，位置不是固定值 0/98200。
- 单次 50 mm 目标后：`0x3A7` 位置发生可重复变化，实体两指同步打开。
- 单次闭合后：位置反馈再次变化，随后才允许一键流程进入闭爪、抬升和释放。
