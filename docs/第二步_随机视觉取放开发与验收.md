# 下一步：随机视觉取放开发与验收

日期：2026-10-12。范围：`simulation/`；对应[第一步报告第 6 节](第一步_单物品闭环开发与验收.md#6-下一步)优先安排的视觉研发任务。

## 1. 本轮做什么

让小球、圆柱体每次出现在不同位置，由相机重新寻找；让操作者选择物品放到哪个区域；保存相机定位与实际物品位置的差异，以及完整取放结果。

已实现的功能：

| 功能 | 操作和实现 |
| --- | --- |
| 随机起点 | 启动和按 R 后，从限定桌面区域均匀抽取新起点；保存种子和每次配置 |
| 相机取物 | 继续用 HSV、形态学、RGB-D 反投影、图像时间戳对应的 TF、视觉状态机、IK 和 MoveIt 路径规划 |
| 选择放置区 | 就绪时按 1 / 2 选择 A / B，RViz 显示区域及高亮；S 后锁定本轮目标 |
| 定位记录 | 抓取执行器发布本轮实际锁定的相机点，记录原图时间戳、世界坐标、参考中心、XY 差异和图像 |
| 取放数据 | 保存物品运动轨迹、实际抬升、最终放置误差、回零误差、控制权期间非零 jog 数和耗时 |
| 复位与退出 | 正常完成后仅重载场景/跟随节点；中途停止后 R 重载整套仿真；退出回收本程序的进程组 |

本轮没有训练新模型。输入是“单个红色物品”，还没有完成多类别识别、脑电指令接入或接触力物理抓取。

## 2. 小白操作步骤

在 Ubuntu 图形桌面打开一个终端，选择其中一个命令：

```bash
cd /home/young1x/robot_projects/piper_robot
./simulation/scripts/run_ball_visual_sim.sh
```

或者：

```bash
cd /home/young1x/robot_projects/piper_robot
./simulation/scripts/run_cylinder_visual_sim.sh
```

1. 等待显示“就绪”，此时 Gazebo、RViz、相机和任务已加载，机械臂等待操作。
2. 保持键盘焦点在启动终端，按 **1** 选 A 区，或 **2** 选 B 区。RViz 中选中的区域及字母为黄色。
3. 看到终端“放置区已选中”的确认后，按 **S**。机械臂进入观测姿态，从相机寻找随机位置的物品，再抓取、抬升、搬到选中区域、释放和回零。
4. 等待“取放完成”，按 **R**。物品出现在新的随机起点；等待“复位完成”后，可以换放置区并再次按 S。
5. 按 **Q** 或 Ctrl+C 结束。需要中途停止则按 **X**，随后按 R 重载复位，或 Q 退出。

所有按键不用回车。运动中改放置区、复位和重复开始都会被拒绝。一次只运行一个物品入口。A/B 区标记显示在 RViz，Gazebo 显示物品实际动作。

下图是使用相同 RViz 配置观察随机试验时的实际画面：A 区已选中，B 区为灰色。开始观测前相机显示 `TARGET LOST` 属于等待目标进入视野；按 S 后会进入观测姿态。

![随机取放的 A/B 放置区和相机画面](images/visual_random_regions.png)

希望再次用同一组随机起点时，在启动命令末尾加 `--seed 20261012`。种子仅重现起点抽样顺序，MoveIt 的采样规划和运行耗时仍可能不同；每次复位或故障重载都会消耗一个新起点。

## 3. 随机区域与算法解释

本轮限定起点为世界坐标 `x ∈ [0.38, 0.42] m`、`y ∈ [-0.12, -0.08] m`。这是此前已验证起点附近的 4 cm × 4 cm 桌面区域，先验证连续随机位置；不能据此声称整张桌面或整个机械臂工作空间都可达。

A 区中心为 `(0.38, 0.12) m`，B 区中心为 `(0.42, 0.12) m`。放置高度沿用物品模型的桌面中心高度。选择通过 ROS 原子参数服务同时更新 XY；执行器只接受有限数值和限定区域，视觉任务进行中拒绝更新。接受后的坐标在工作线程开始时读取，本轮中保持不变。

随机起点写入一份 YAML，并同时提供给场景管理器和跟随节点。R 后替换这一对节点，避免物品生成在新位置、跟随节点却仍记着旧起点。Gazebo 实际位置与预期相差小于 1 mm、场景就绪且机械臂回零后，才允许开始。

随机生成的坐标用于布置场景和检验参考。抓取 XY 来自检测图像，经 RGB-D 和同一图像时间的 TF 转到世界坐标后锁定；没有调用固定坐标抓取接口。场景仍提供物品尺寸、中心高度和碰撞模型，当前流程不是未知形状/未知高度抓取。

## 4. 定位误差怎么理解

检测器给出的是物品的**可见表面点**，Gazebo 给出的是几何模型中心。两者天然可能不同，圆柱体尤其明显。因此本轮记录：

- `xy_error_m`：世界坐标水平面上的距离差，单位米；用于了解当前抓取位置的偏差。
- `delta_xyz_m`：三个方向的有符号差值。
- `z_surface_center_difference_m`：表面与中心在高度上的差异，不能直接叫相机标定误差。
- `image_stamp_ns`、坐标系、视觉点、静态起点的 Gazebo 中心参考、锁定附近的 RGB 图像及其时间戳。

执行器发布的点就是本轮锁定、用于生成抓取候选的点。参考取自场景就绪后的实际静态物品中心；Gazebo ModelStates 没有原生时间戳，本轮不声称已经实现运动目标的逐图像真值配准。截图采用锁定通知时最新收到的图像，另存截图时间戳，可能与定位原帧有小幅时间差。

统计输出每种物品的样本数、均值、中位数、P95 和最大水平差异。P95 使用最近秩法，10 个样本时等于最大值。每轮锁定样本是独立试验单位，不能把视频几十帧每秒直接当作几十次独立抓取。后续应加球/圆柱拟合，把表面点转换为几何中心，再用独立标定数据评估定位精度。

## 5. 保存的数据与复现

每次运行会打印数据目录 `simulation/log/visual_sim/<物品-时间>/`：

| 文件 | 内容 |
| --- | --- |
| `session.json` | 每轮起点、放置区、结果、误差、轨迹、随机种子和定位统计；临时文件 fsync 后原子替换 |
| `scene-NNN.yaml` | 各随机场景的精确配置，可检查和复现 |
| `scene-NNN-lock-NN.png` | 锁定通知附近收到的 RGB 图像 |
| `events.jsonl` | 状态、拒绝请求、锁定测量和进程启停记录 |
| `NN-scene-NNN.log` | 每次重建场景的独立日志，避免复位覆盖旧日志 |
| `NN-*.log` / `ros_logs/` | Gazebo、MoveIt、检测器、任务及窗口日志 |
| `trial_plan.json` | 批量验收开始前保存的种子、起点、放置区顺序和首个失败即停止规则 |

研发验收的显式无窗口命令如下，**这会自动执行 10 轮虚拟机械臂运动**；日常观看仍使用第 2 节按键入口：

```bash
cd /home/young1x/robot_projects/piper_robot/simulation
./scripts/run_ball_visual_sim.sh --headless --seed 20261012 --batch-trials 10
./scripts/run_cylinder_visual_sim.sh --headless --seed 20261012 --batch-trials 10
```

两个命令依次运行，不能同时运行。批量试验交替放到 A/B 区，遇到移动试验失败就停止并保留数据。只有开始服务明确返回“尚无新鲜关节反馈”、机械臂尚未运动时，允许在同一场景重试最多 10 秒；拒绝记录独立保留。

导出试验与定位 CSV 的命令（把会话目录替换为实际路径，输出目录需尚不存在）：

```bash
/usr/bin/python3 -s scripts/analyze_visual_randomization.py \
  log/visual_sim/实际小球会话目录 log/visual_sim/实际圆柱体会话目录 \
  --output validation/visual_randomization/新的统计目录
```

## 6. 验收记录

端到端门槛：进入 COMPLETE 并释放控制权、实际抬升至少 5 cm、最终位置距所选区中心小于 3 cm、六个关节最大回零误差小于 0.02 rad、执行器控制权期间没有非零视觉 jog，并且有本轮锁定视觉点记录。位置按 Gazebo 物品实际状态采集，不用跟随指令代替。

当前构建通过；现有 45 个算法用例与 6 个 CTest 目标通过，colcon 汇总为 51 项、0 错误、0 失败。预定随机试验已全部通过：小球 10/10、圆柱体 10/10，每种物品 A/B 区各 5 次；本轮数据保存在 `simulation/validation/visual_randomization/`，不混入上一阶段的 40 次静态起点验收。

| 物品 | 通过 / 试验数 | 每轮耗时 | 实际最高抬升 | 水平差异均值 / P95 / 最大值 |
| --- | --- | --- | --- | --- |
| 小球 | 10 / 10 | 40.26–43.43 s | 12.00–12.53 cm | 6.34 / 6.80 / 6.80 mm |
| 圆柱体 | 10 / 10 | 42.06–60.03 s | 12.00–12.73 cm | 15.53 / 16.48 / 16.48 mm |

20 轮全部有新鲜锁定坐标、图像和物品运动轨迹，执行器控制权期间非零 jog 数为 0；最大回零误差约 0.000102 rad。放置误差都小于 3 cm；原始记录约 0.012 mm 的极小误差来自强制位姿跟随，不能解释为真实机械臂的放置精度。两组最终批量序列均无开始拒绝。

补充检查：运动中改变放置区域、越界值、NaN 和错误参数类型均被拒绝，更新前后原 XY 保持一致。新标记初次未显示，按本机 RViz 头文件确认使用 `Topic` 字段后修正；默认视角和字母标签也已调整，最终画面已实际观察。圆柱体验收后只改过标记绘制和 RViz 布局，运动、起点生成、复位与数据处理函数保持一致，精确源码版本及 AST 比较结果已保存。
