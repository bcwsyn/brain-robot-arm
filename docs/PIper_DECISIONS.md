- Linux 主线 `gs_usb` 将超出 `GS_MAX_TX_URBS` 的 echo id 视为无效设备回显并丢弃。该内核证据可说明 USB-CAN 回显异常，但在接口仍 `ERROR-ACTIVE`、RX 增长且无 bus-off 时，不得把它描述为 CAN 总线断开或 PiPER 固件故障。
- 适配器失能必须成为上游控制状态：`adapter_armed` 从 true 变 false 时，视觉控制器进入 `PIPER_ADAPTER_DISARMED` 故障并停止规划；禁止继续发布看似成功、实际未执行的搜索轨迹。
