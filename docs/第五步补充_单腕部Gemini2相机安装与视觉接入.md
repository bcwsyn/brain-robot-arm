# 第五步补充：单腕部 Gemini 2 相机安装与视觉接入

日期：2026-10-14。开发范围：`simulation/`。GitHub 新版本目录：`simulation_cup_wrist/`。承接[第五步固定相机验收报告](第五步_水杯视觉估径与力反馈抓取开发与验收.md)；原版本及数据完整保留。

## 1. 本次目标与实现范围

用户只有一台 Gemini 2 深度相机，安装在夹爪侧面，要求视觉工作全部来自腕部相机；同时根据实物照片调整相机位置。已将仿真水杯入口的原始 RGB、深度、内参、YOLO、外径估计及目标坐标统一接到腕部相机，删除该入口创建的固定外部传感器及其静态世界外参。

本次没有重新训练 YOLO，也不修改真实机械臂工作区。RViz 的杯子规划包络圆柱继续保留，Gazebo 的台阶中空杯不改变。本次不是完整重做上一阶段全部直径和故障验收。

## 2. 安装位置与官方参数

用户照片见[安装参考图](wrist_camera/mount_reference.png)。图中的 105 mm、30 mm 是沿夹爪方向的近似尺寸。模型以 `gripper_base` 法兰坐标为参考，将相机前端名义光学平面移到 `z=30.8 mm`，指尖参考位置为 `z=135.8 mm`，轴向差为 105 mm。原模型相机参考位置 `z=75 mm` 已后移 44.2 mm。

现有指爪/本体连接网格约在 `z=59.3–63 mm`，相机前端位于其后约 `28.5–32.2 mm`，与图中 `d2≈30 mm` 的夹爪根部间距一致。

横向位置 `x=-55 mm、y=0` 和朝向沿用仿真假设。照片无法提供精确光心、相机滚转/俯仰及支架六自由度外参；未将这些近似值标为实机手眼标定。两个轴向尺寸也不是相机到指尖的三维直线距离。

依据 [Orbbec Gemini 2 datasheet v1.1](https://www.orbbec.com/wp-content/uploads/2023/04/ORBBEC_Datasheet_Gemini-2-3.pdf)，外壳宽×高×深为 90×25×30 mm，质量 97 g，有效深度范围 0.15–10 m。仿真使用 640×480 配准 RGB-D、约 63° RGB 水平视场、5 Hz 图像；此为对齐到 RGB 的理想深度图，没有模拟原生 IR 全视场、双目匹配、完整畸变或厂商 D2C。

新增共享 `piper_description/urdf/gemini2_wrist_camera.xacro`，Gazebo 和 MoveIt 共同包含外观、外壳碰撞包络和安装坐标。光学 `+Z` 与夹爪向前轴一致，图像时刻通过关节反馈 TF 转到世界坐标。机械臂动力学仍保留原有理想重力补偿前提。

## 3. 单相机视觉流程

```text
腕部 RGB / 配准深度 / 内参
    → YOLO 实例掩膜
    → 各实例的有效深度、直立杯高度、未知局部外径和不确定度检查
    → 只接受唯一通过几何检查的杯子
    → 图像时刻 world ← wrist_camera_optical_frame
    → 锁定同一帧外径、预张开和抓取点
    → 接近、力反馈闭合、物理取放
```

三个视觉输入分别为 `/wrist_camera/wrist_camera/image_raw`、`/wrist_camera/wrist_camera/depth/image_raw` 和 `/wrist_camera/wrist_camera/camera_info`。生成的世界文件不包含 `cup_observer`。不从 Gazebo 物品位姿生成抓取点或相机观察目标。

零位相机难以完整看到 200 mm 高杯，所以启动后先用 MoveIt 规划一个缓慢、碰撞检查过的固定桌面观察姿态 `[-0.27, 0, 0, 0, 0.44, 0] rad`。此时杯子抓取执行器尚未启动。每次复位重新进入观察位，完成取放后仍回机械臂零位。

相机距指尖 105 mm 小于最小有效深度 150 mm，近距离图像可能缺深度或被夹爪遮挡。因此在远处锁定 RGB-D/TF/掩膜与估径包，近距离继续使用锁定目标和实时接触力。界面保留最近有效外径，不把它描述为近距离视觉持续重估。

## 4. 调试发现与修复

| 发现 | 修复与证据 |
| --- | --- |
| 新 XML 注释含冒号空格，Gazebo 的 ROS 参数解析失败，控制器启动超时 | 调整注释，模型核验同时检查展开 URDF 能通过 ROS 使用的 YAML 解析；失败会话保留 |
| 腕部画面里的真实杯置信度约 0.956，夹爪边缘被误识别为第二个杯约 0.427 | 对每个掩膜分别做 RGB-D 几何检查，夹爪因有效深度不足被拒绝；有效杯继续通过 |
| 单纯取最高置信度会绕过多杯歧义 | 保持唯一有效杯要求；两个几何有效实例仍拒绝启动 |

保存实际腕部帧形成回归样本 `test/data/wrist_cup_and_finger.npz`，附模型哈希、图像来源及检测框元数据。新增四个检查验证实例顺序变化、只有夹爪、多个有效实例时的行为。

## 5. 当前验收结果

固定代码的 75 mm 水杯两轮批次均通过，随机种子 `20261015`，依次放置 A/B 区；每轮之间完整重建仿真，不在失败后自动重试。原始会话为 `cup-20261014-220858-542297`。

| 视觉外径 | 74.87 mm | 74.85 mm |
| 视觉杯高 | 200.09 mm | 200.08 mm |

| 实际最大抬升 | 144.80 mm | 144.82 mm |

两轮均验证实际夹持、抬升、保持、释放落稳和回零。初始诊断记录 `image_frame=wrist_camera_optical_frame`，二维识别两个实例而几何有效杯只有一个。目标生成使用图像和时间匹配 TF，Gazebo 真值只服务于独立物理验收。

核心汇总检查为 **96 项，0 失败、0 错误、0 跳过**，包括原核心检查和新增四个回归用例及其 CTest 目标。模型核验验证两套 URDF 坐标一致、105 mm 轴向距离、光学方向、外壳尺寸和 150 mm 最小深度。

图形窗口与独立发布工作区验证记录见 `validation/wrist_camera_mount_20261014/final_validation.json`。原固定相机 9/9 正测和 5/5 负测继续属于上一版本；本版尚未重新执行全部 55/85 mm 与五种故障批次，不能沿用历史通过率。

独立发布工作区七包从空 build/install 构建完成，约 2 分 1 秒，96 项核心检查通过；复用本机已安装的私有视觉环境，没有重新安装系统依赖。发布目录图形取放单独通过 1/1，放置误差 1.345 mm，保持 3.15 仿真秒；完成后 `R` 重新进入观察位并识别，`Q` 正常退出。该轮同时作为发布运行检查，不重复计入上方两轮批次。实时图像话题核验确认 RGB/深度各一个发布者、图像坐标为腕部光学坐标、无外部相机话题。
